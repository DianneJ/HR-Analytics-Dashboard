# HR Analytics Dashboard
## Project Overview
Developed an interactive Power BI dashboard to analyze workforce demographics, employee attrition, compensation patterns, and department-level retention trends.

The dashboard transforms raw HR data into meaningful business insights that support workforce planning and employee retention initiatives.

## Business Problem
Organizations need visibility into employee turnover and workforce demographics to identify retention risks and support strategic workforce planning.

This dashboard helps decision-makers understand workforce composition, identify potential retention challenges, and evaluate turnover trends across departments, salary bands, and demographic groups.

### Tools Used
- Power BI
- Power Query
- DAX
- Data Modeling
  
### Dashboard Features
- Employee Count KPIs
- Attrition Rate Analysis
- Department-Level Reporting
- Salary Distribution Analysis
- Employee Satisfaction Metrics
- Workforce Demographics
- Interactive Slicers and Filtering
  
### Data Preparation
Prepared and transformed HR employee data using Power Query by cleaning records, validating data quality, standardizing values, and creating calculated fields to support workforce analysis.

Created DAX measures to calculate key performance indicators including employee counts, attrition rates, demographic distributions, and workforce metrics.

### Key Insights
- Identified departments with higher rates of attrition.
- Analyzed turnover across salary bands and experience levels.
- Examined workforce demographics including age and gender distributions.
- Evaluated employee satisfaction trends and retention indicators.
- Highlighted workforce characteristics that may support retention planning initiatives.
